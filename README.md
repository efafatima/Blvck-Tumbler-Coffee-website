# ☕ Blvck Tumbler Coffee Website

A modern and responsive coffee shop website built with React, Vite, and Tailwind CSS.

The website provides an elegant user experience with a clean interface, showcasing coffee products, featured sections, and a visually appealing design optimized for all screen sizes.

## 🌐 Live Demo

https://blvck-tumbler-coffee-website-5vsfman3o-efafatimas-projects.vercel.app/

## ✨ Features

- Modern and responsive UI
- Mobile-friendly design
- Fast performance with Vite
- Styled using Tailwind CSS
- Interactive navigation
- Hero section with call-to-action
- Featured coffee products
- Smooth scrolling experience
- Reusable React components
- Optimized for different screen sizes

## 🛠️ Tech Stack

- React.js
- Vite
- Tailwind CSS
- JavaScript (ES6+)

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/efafatima/Blvck-Tumbler-Coffee-website.git
```

Navigate to the project directory:

```bash
cd Blvck-Tumbler-Coffee-website
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
